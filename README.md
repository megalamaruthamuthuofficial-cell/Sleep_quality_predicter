🌙 Sleep Quality Predictor

A Machine Learning-based web application that predicts a user's sleep quality using health and lifestyle factors. The project is developed using **Python, Flask, Machine Learning, HTML, CSS, and JavaScript**.

📌 Project Objective

The objective of this project is to analyze user sleep habits and predict whether the sleep quality is **Good, Average, or Poor**. The system also provides AI-based bedtime recommendations, personalized sleep improvement tips, and motivational sleep quotes.

🚀 Features

- Sleep Quality Prediction
- User-Friendly Web Interface
- Loading Animation ("Analyzing...")
- AI Bedtime Recommendation
- AI Sleep Improvement Tips
- Random Sleep Quotes
- Responsive Design
- Machine Learning Prediction using Health Data

▶️ How to Run

1. Clone the repository.
2. Install the required packages:

pip install -r requirements.txt

3. Run the application:

python app.py

4. Open your browser and visit:

http://127.0.0.1:5000


📊 Machine Learning Model

The model is trained using the **Sleep Health and Lifestyle Dataset** and predicts sleep quality based on user inputs.
